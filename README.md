# 🐦 Skvorling (Скворлинг) — Пассивный английский в контексте

**Сайт:** [skvorling.ru](https://skvorling.ru) · **Платформа:** Chrome, Яндекс Браузер, Edge, Brave, Arc (Manifest V3)

**Skvorling** — браузерное расширение для пассивного изучения английского языка. Вы читаете привычные русскоязычные статьи, новости и комментарии, а расширение мягко заменяет очевидные слова в длинных предложениях на актуальные английские формы. Мозг сам догадывается о смысле из контекста и запоминает лексику естественно — без уроков, карточек и отдельного времени.

## Основные возможности

- **Обучение на вашей реальности:** вы встречаете английские слова не в искусственных диалогах учебника, а в тех статьях и темах, которые реально читаете каждый день.
- **Умный контекстный отбор (1 054+ слов):** 894 базовых слова (CEFR A1–C1) + 4 подключаемых тематических пакета (🔧 IT и техника, 💼 Бизнес, 📖 Литература, 🩺 Медицина) + 30 естественных контекстных фраз (*in fact, makes sense, at least, step by step*).
- **Живая русская морфология:** перевод с учётом времён, причастий, степеней сравнения и падежей (`работает → works`, `работал → worked`, `работающий → working`, `быстрее → faster`, `рукой → by hand`).
- **Чистота языка:** защита устойчивых фраз (*«друг за другом»*, *«на белом свете»*), разбор омоформ (*«на дне бутылки» → bottom* vs *«на дне знаний» → day*) и пропуск имён собственных в середине предложения.
- **Адаптивный прогресс и скрытие изученного:** 5 просмотров слова в области видимости без подсказки автоматически переводят его в «Освоено» и скрывают со страниц (можно переключить в режим накопления %). По мере роста словаря плотность сама увеличивается с 1 до 5 слов на предложение.
- **Удобный UX:** 3 темы (`☀️ Светлая`, `🎨 Красочная`, `🌙 Тёмная`), 3 стиля подсветки, озвучка Web Speech API (US/UK), навигатор по словам (`Alt+Shift+F`), вкладка `⭐ Избранное` для активного повторения, синхронизация через аккаунт браузера (`chrome.storage.sync`) и 100% локальная приватность.

## Установка расширения за 60 секунд

1. Скачайте и распакуйте `skvorling-extension.zip` в постоянную папку на диске.
2. Откройте страницу расширений: `chrome://extensions` (или `browser://extensions` в Яндекс Браузере / `edge://extensions` в Edge).
3. Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `skvorling-extension`.

## Горячие клавиши

- `Alt + Shift + E` — быстро включить или выключить Skvorling на текущей странице.
- `Alt + Shift + F` — открыть навигатор по переведённым словам на странице (в стиле `Ctrl+F`).
- `Alt + Клик` по слову — мгновенно вернуть русский оригинал.
