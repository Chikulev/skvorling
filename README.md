# Skvorling (`skvorling.ru`) — Официальный сайт

Готовый статический сайт для **GitHub Pages** с живой песочницей, интерактивной демо-статьёй, файлом `CNAME` под домен `skvorling.ru`, манифестом обновлений `update.json` и готовым архивом `skvorling-extension.zip` для скачивания в 1 клик.

## Запуск на GitHub Pages за 3 шага

1. Загрузите все файлы из этого архива в **корень** вашего GitHub-репозитория (ветка `main`).
2. Откройте в репозитории **Settings → Pages**:
   - **Source:** `Deploy from a branch` → ветка `main`, папка `/ (root)` → **Save**.
   - **Custom domain:** убедитесь, что указано `skvorling.ru` (подхватится автоматически из файла `CNAME`), и включите **Enforce HTTPS** (появится через 5–15 минут после обновления DNS).
3. В панели регистратора домена `skvorling.ru` пропишите стандартные DNS-записи GitHub Pages:
   - 4 `A`-записи для `@` (корневого домена):
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - 1 `CNAME`-запись для `www` → `<ваш-логин-github>.github.io`.
