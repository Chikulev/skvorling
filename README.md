# Skvorling (Скворлинг) v2.2 — Пассивный английский в контексте

Браузерное расширение (Manifest V3) для Chrome, Яндекс Браузера, Edge, Brave и Arc.
Находит длинные русскоязычные предложения и заменяет наиболее полезные и очевидные из контекста слова на актуальные английские формы (с учётом времён, причастий, чисел и падежей).

## Установка за 1 минуту

1. Распакуйте архив `skvorling-extension.zip` в постоянную папку (например, `C:\Extensions\skvorling-extension`).
2. Откройте страницу расширений:
   - **Chrome / Brave / Arc:** `chrome://extensions`
   - **Яндекс Браузер:** `browser://extensions`
   - **Microsoft Edge:** `edge://extensions`
3. Включите **«Режим разработчика»** (правый верхний угол).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `skvorling-extension`.
5. Автоматически откроется встроенная демо-статья v2.0 — можно сразу проверить навигатор, рандомайзер и перевод форм.

## Новое в v2.0

- **Навигатор по переведённым словам (`Alt+Shift+F`):** плавающая панель в стиле `Ctrl+F` для перескакивания по переведённым словам (`↑ / ↓` или `Enter`), с фильтром «Все / Новые», озвучкой и кнопкой перетасовки `🎲`.
- **Глубокая морфология (времена, причастия, падежи, сравнения):** `работает → works`, `работал → worked`, `работающий → working`, `быстрее → faster`, `рукой → by hand / hand`, `ключом → with a key` с грамматической подсказкой в tooltip.
- **Шкала пользы (`utility` 1–5) + Умный рандомайзер:** отбор идёт по формуле «базовая польза + очевидность + контекстные якоря», а отключаемый Top-Pool рандомайзер выбирает слова из пула лучших кандидатов, уникализируя переводы на каждом чтении.
- **Обновления и пакеты слов:** проверка новых версий по `update.json` и импорт тематических JSON-паков слов в «Настройки и данные» без переустановки расширения.
